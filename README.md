# Phoenix Platform

## Phoenix Core v0.1.0

El núcleo contiene los contratos básicos e inmutables que todos los componentes de Phoenix utilizan para comunicarse:

- **Config** — configuración central del sistema
- **IDs** — generación y validación de identificadores únicos por tipo
- **Events** — formato común para eventos internos
- **Signals** — estructura de señales emitidas por los bots
- **Orders** — contrato de órdenes internas antes de llegar al exchange
- **Trades** — representación de operaciones abiertas
- **Portfolio** — agrupación de bots bajo un identificador común
